# Commdesk

**让设备通信调试更清晰、更顺手。**

Commdesk 是一款适用于 Windows 的中文通信调试工具，面向嵌入式开发、设备联调和现场排查。你可以连接设备、查看收发数据、管理常用命令，也可以用脚本完成重复调试操作。

## 你可以用它做什么

- **连接设备**：支持串口、蓝牙、TCP 和 UDP，并提供虚拟串口工具。
- **查看通信数据**：以文本或十六进制查看收发内容，支持时间戳、搜索、筛选、暂停滚动和导出。
- **保存调试记录**：通信原始数据保存在本地，方便回看和排查问题。
- **管理常用命令**：用文件夹整理文本、十六进制和脚本命令，通过独立编辑窗口修改内容。
- **运行调试脚本**：支持 Lua 和 C，可编写收发流程、创建交互控件，减少重复操作。
- **解析 UniBus 协议**：内置 UniBus 协议解析预置，可在协议列表中选择使用，查看已支持的帧和业务字段；也可以编辑协议文件。
- **灵活安排工作区**：按当前任务调整通信、命令、脚本和输出区域。

## 开始使用

1. 启动软件，选择连接方式，核对串口或网络参数后连接设备。
2. 在通信窗口查看数据，按需要发送文本、十六进制内容或常用命令。
3. 需要 UniBus 解析时，在协议列表选择 `unibus`；需要自定义流程时，使用 Lua / C 脚本。
4. 退出前停止脚本、断开连接，并保存编辑内容。

更多操作说明和脚本帮助随下载包提供。

## 运行环境

- Windows 10 / 11，64 位系统。
- Microsoft Edge WebView2 Runtime。
- 正常使用不需要安装 Node.js、Rust 或编程工具。

## 便携与更新

软件设置、命令、协议和通信记录保存在程序所在文件夹中，**复制整个文件夹即可迁移**。建议解压到有写入权限的位置。

在软件设置中检查更新即可获取后续版本。更新优先使用 Gitee，访问失败时尝试 GitHub；下载完成后自动校验并重新启动。更新会保留已有设置、命令、协议和日志。

## 使用提示

- 连接和发送前，请确认设备及通信参数。
- 只运行来源可信的脚本。
- 虚拟串口驱动操作可能需要管理员授权。
- UniBus 仅解析已支持的业务布局，未知内容保留为原始数据。
- 本软件仍在持续完善，设备与驱动兼容性请以实际使用情况为准。
